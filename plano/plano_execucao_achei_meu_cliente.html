Estrutura do banco DuckDB — tabela única
Uma tabela chamada empresas com todas as 34 colunas originais + 2 colunas que adicionamos. Total: 36 colunas, 2,97M linhas.
COLUNAS ORIGINAIS (das suas 34) + 2 QUE ADICIONAMOS
CNPJ
PK · TEXT
Chave primária. Deduplicação por aqui.
SEGMENTO
NOVO · TEXT
Salões, Distribuidores, Lojas, Fábricas, Clínicas, Representantes
ESTADO
INDEX · TEXT
SP, RJ, MG… — filtro principal do usuário
MUNICIPIO
INDEX · TEXT
Cidade — segundo filtro mais usado
BAIRRO
TEXT
Nível mais granular de localização
RAZÃO SOCIAL
TEXT
Nome jurídico — usado no filtro de keyword
NOME FANTASIA
TEXT
Nome comercial — também no filtro de keyword
WHATSAPP_1
INDEX · TEXT
Contato principal. Filtro TEM_WHATSAPP.
E-MAIL
TEXT
Contato secundário
TEM_EMAIL
INDEX · BOOL
Filtro rápido "só com e-mail"
TEM_TELEFONE
INDEX · BOOL
Filtro rápido "só com telefone"
EMAIL_CONTABILIDADE
BOOL · excluir
Filtro negativo — remove contador
PORTE
INDEX · TEXT
MEI, ME, EPP, Médio, Grande
MEI
BOOL
Filtro rápido "só MEI" ou "excluir MEI"
INICIO ATIVIDADE
DATE
Filtro "abertas nos últimos 30/60/90 dias" → novidades
CNAE_PRINCIPAL_CODIGO
INDEX · TEXT
Filtro avançado por CNAE exato
MAPS
TEXT
Link direto para Google Maps — clicável na tabela
ARQUIVO_ORIGEM
NOVO · TEXT
Nome do CSV de origem — rastreabilidade
